# Bundled fonts

Used only by the workshop scenes (`src/components/Workshop.jsx`, `@font-face` in `src/index.css`).
They are shipped with the app so that no font server is contacted. Latin subset, WOFF2, taken
from the `@fontsource` packages of the same names.
